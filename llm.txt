# YumeKit (@waggylabs/yumekit)

A modern, framework-agnostic Web Components UI kit providing 23 production-ready custom HTML elements. Built entirely on native web standards with zero external runtime dependencies.

## Version
0.2.5

## License
MIT

## Installation

```bash
npm install @waggylabs/yumekit
```

## Key Characteristics
- Pure Web Components (Custom Elements v1, Shadow DOM, ElementInternals)
- Zero runtime dependencies
- Full TypeScript support with type declarations
- Tree-shakeable ESM modules
- ARIA-compliant and keyboard-navigable
- Design token system via CSS custom properties
- Multiple built-in themes (blue-light, blue-dark, orange-light, orange-dark)
- React JSX type declarations included
- Form-associated components with native HTML form API support
- Security-focused SVG icon sanitization (allowlist-based)

## Entry Points (package.json exports)

- `@waggylabs/yumekit` — full ESM bundle
- `@waggylabs/yumekit/react` — React JSX type declarations
- `@waggylabs/yumekit/components/y-{name}` — individual components
- `@waggylabs/yumekit/icons/all.js` — all pre-built icons
- `@waggylabs/yumekit/icons/registry` — icon registry API
- `@waggylabs/yumekit/styles/{name}.css` — theme CSS files

CDN (IIFE):
```html
<script src="https://cdn.jsdelivr.net/npm/@waggylabs/yumekit/dist/yumekit.min.js"></script>
```

## Usage Patterns

### Full Import
```javascript
import "@waggylabs/yumekit";
```

### Tree-Shaken Import
```javascript
import "@waggylabs/yumekit/components/y-theme";
import "@waggylabs/yumekit/components/y-button";
import "@waggylabs/yumekit/components/y-input";
```

### Icons
```javascript
import { registerIcon, registerIcons, getIcon } from "@waggylabs/yumekit";
import "@waggylabs/yumekit/icons/all.js"; // load all 60+ pre-built icons
```

### React
```jsx
import "@waggylabs/yumekit";
// JSX types are auto-resolved via react.d.ts

function App() {
  return (
    <y-theme theme="blue" mode="light">
      <y-button color="primary">Click me</y-button>
    </y-theme>
  );
}
```

## Component Reference

All custom elements are prefixed with `y-`.

### y-theme
Theme provider. Wraps your app and injects design tokens as CSS custom properties.

Attributes:
- `theme` — `"blue"` | `"orange"` — built-in palette name
- `mode` — `"light"` | `"dark"`
- `theme-path` — URL to a custom CSS theme file
- `cross-origin` — boolean, enables CORS for remote theme loading

```html
<y-theme theme="blue" mode="light">
  <!-- app content -->
</y-theme>
```

### y-button
Pressable button with icon support.

Tag: `<y-button>`
Attributes:
- `color` — `"base"` | `"primary"` | `"secondary"` | `"success"` | `"warning"` | `"error"` | `"help"`
- `size` — `"small"` | `"medium"` (default) | `"large"`
- `style-type` — `"filled"` (default) | `"outlined"` | `"flat"`
- `left-icon` — icon name (from registry)
- `right-icon` — icon name (from registry)
- `disabled` — boolean
- `type` — `"button"` | `"submit"` | `"reset"` (default: `"button"`)

```html
<y-button color="primary" size="large" left-icon="check">Save</y-button>
```

### y-input
Text input field. Form-associated.

Tag: `<y-input>`
Attributes:
- `type` — `"text"` | `"email"` | `"password"` | `"number"` | `"tel"` | `"url"` | `"search"`
- `name` — form field name
- `value` — current value
- `placeholder`
- `label` — visible label text
- `label-position` — `"top"` (default) | `"bottom"` | `"left"` | `"right"`
- `size` — `"small"` | `"medium"` | `"large"`
- `disabled` — boolean
- `readonly` — boolean
- `required` — boolean
- `invalid` — boolean, applies error state
- `max-length` — numeric string
- `min-length` — numeric string
- `pattern` — validation regex

Events: `change`, `input`

```html
<y-input type="email" name="email" label="Email" required></y-input>
```

## Design Token System (CSS Custom Properties)

Applied by y-theme or by manually including a theme CSS file. Variables follow this naming pattern:

```
--y-{scheme}-background-app
--y-{scheme}-background-component
--y-{scheme}-background-hover
--y-{scheme}-background-active
--y-{scheme}-background-border
--y-{scheme}-content
--y-{scheme}-content-inverse
```

Where `{scheme}` is: `base`, `primary`, `secondary`, `success`, `warning`, `error`, `help`

Additional tokens:
```
--y-spacing-xs, --y-spacing-sm, --y-spacing-md, --y-spacing-lg, --y-spacing-xl
--y-font-size-sm, --y-font-size-md, --y-font-size-lg
--y-border-radius-sm, --y-border-radius-md, --y-border-radius-lg, --y-border-radius-full
--y-shadow-sm, --y-shadow-md, --y-shadow-lg
```

To create a custom theme, define these CSS variables in a stylesheet and point y-theme at it:
```html
<y-theme theme-path="/custom-theme.css"></y-theme>
```

## Icon Registry API

```javascript
import { registerIcon, registerIcons, getIcon } from "@waggylabs/yumekit";

// Register one icon (raw SVG string)
registerIcon("my-icon", `<svg viewBox="0 0 24 24">...</svg>`);

// Register many at once
registerIcons([
  { name: "icon-a", svg: `<svg>...</svg>` },
  { name: "icon-b", svg: `<svg>...</svg>` },
]);

// Retrieve
const svg = getIcon("my-icon");
```

Pre-built icon categories (loaded via `import "@waggylabs/yumekit/icons/all.js"`):
- Accessibility (accessible, eye, eye-off, …)
- Arrows (arrow-up/down/left/right, chevrons, …)
- Actions (check, close, copy, download, edit, trash, …)
- Communication (bell, chat, email, phone, …)
- Media (camera, image, mic, play, pause, …)
- Navigation (home, menu, search, settings, …)
- UI (lock, star, heart, info, warning, error, …)

## TypeScript Support

Types are in `dist/index.d.ts`. React JSX types are in `dist/react.d.ts` and auto-resolved via the `react` export condition.

For non-React TypeScript projects, augment `HTMLElementTagNameMap`:
```typescript
// Already included in the library's type declarations.
// Just import the library and use elements with full type safety.
import "@waggylabs/yumekit";
```

## Helper Functions (internal, `src/modules/helpers.js`)

These are not exported in the public API but are used internally:

- `getColorVarPair(color, fallbackColor)` — resolves a color name to CSS var pair
- `hideEmptySlotContainers(shadowRoot, config)` — hides wrappers when slots are empty
- `resolveCSSColor(varExpr, element)` — resolves CSS variable to computed color
- `parseColor(colorStr)` — parses hex/rgb to `{r, g, b}`
- `luminance({r,g,b})` — WCAG relative luminance
- `contrastTextColor(bgColor)` — returns `"#000"` or `"#fff"` for best contrast
