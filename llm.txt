# YumeKit (@waggylabs/yumekit)

A modern, framework-agnostic Web Components UI kit providing 31 production-ready custom HTML elements. Built entirely on native web standards with zero external runtime dependencies.

## Version
0.4.1

## License
MIT

## Installation

```bash
npm install @waggylabs/yumekit
```

## Key Characteristics
- Pure Web Components (Custom Elements v1, Shadow DOM, ElementInternals)
- Zero runtime dependencies
- Full TypeScript support with type declarations
- Tree-shakeable ESM modules
- ARIA-compliant and keyboard-navigable
- Design token system via CSS custom properties
- 22 built-in themes across 11 color families (blue, orange, green, red, teal, yellow, indigo, purple, pink, brown, olive) × dark and light variants
- React JSX type declarations included
- Form-associated components with native HTML form API support
- Security-focused SVG icon sanitization (allowlist-based)

## Entry Points (package.json exports)

- `@waggylabs/yumekit` — full ESM bundle
- `@waggylabs/yumekit/react` — React JSX type declarations
- `@waggylabs/yumekit/components/y-{name}` — individual components
- `@waggylabs/yumekit/icons/all.js` — all pre-built icons
- `@waggylabs/yumekit/icons/registry` — icon registry API
- `@waggylabs/yumekit/styles/{name}.css` — theme CSS files (e.g. `blue-dark.css`, `purple-light.css`, `olive-dark.css`)

CDN (IIFE):
```html
<script src="https://cdn.jsdelivr.net/npm/@waggylabs/yumekit/dist/yumekit.min.js"></script>
```

## Usage Patterns

### Full Import
```javascript
import "@waggylabs/yumekit";
```

### Tree-Shaken Import
```javascript
import "@waggylabs/yumekit/components/y-theme";
import "@waggylabs/yumekit/components/y-button";
import "@waggylabs/yumekit/components/y-input";
import "@waggylabs/yumekit/components/y-date";
import "@waggylabs/yumekit/components/y-datepicker";
```

### Icons
```javascript
import { registerIcon, registerIcons, getIcon } from "@waggylabs/yumekit";
import "@waggylabs/yumekit/icons/all.js"; // load all 100+ pre-built icons
```

### React
```jsx
import "@waggylabs/yumekit";
// JSX types are auto-resolved via react.d.ts

function App() {
  return (
    <y-theme theme="blue-light">
      <y-button color="primary">Click me</y-button>
    </y-theme>
  );
}
```

## Component Reference

All custom elements are prefixed with `y-`.

### y-theme
Theme provider. Wraps your app and injects design tokens as CSS custom properties.

Attributes:
- `theme` — built-in palette name or a URL/path to a custom CSS theme file. Built-in names: `"blue-light"` | `"blue-dark"` | `"orange-light"` | `"orange-dark"` | `"green-light"` | `"green-dark"` | `"red-light"` | `"red-dark"` | `"teal-light"` | `"teal-dark"` | `"yellow-light"` | `"yellow-dark"` | `"indigo-light"` | `"indigo-dark"` | `"purple-light"` | `"purple-dark"` | `"pink-light"` | `"pink-dark"` | `"brown-light"` | `"brown-dark"` | `"olive-light"` | `"olive-dark"`
- `cross-origin` — boolean, enables CORS for remote theme URLs
- `no-default-font` — boolean, skips injecting the default Lexend font from Google Fonts

```html
<y-theme theme="blue-light">
  <!-- app content -->
</y-theme>
```

### y-date
Date input field with popup calendar. Form-associated.

Tag: `<y-date>`
Attributes:
- `mode` — `"single"` (default) | `"range"`
- `name` — form field name
- `value` — ISO date string, or `"ISO,ISO"` comma-pair for range mode
- `min`, `max` — date constraints (ISO string)
- `format` — display format string. Tokens: `YYYY` `MM` `DD` `HH` `hh` `mm` `ss` `A` `a` (default: `"MM/DD/YYYY"`)
- `placeholder` — placeholder text when no date is selected
- `color` — color scheme for the datepicker (default: `"primary"`)
- `size` — `"small"` | `"medium"` (default) | `"large"`
- `label-position` — `"top"` (default) | `"bottom"`
- `clearable` — boolean, shows a clear (×) button when a value is set
- `disabled` — boolean
- `invalid` — boolean, applies error state
- `show-hours` — boolean, show hour column in time picker
- `show-minutes` — boolean, show minutes column (implies `show-hours`)
- `show-seconds` — boolean, show seconds column (implies `show-minutes`)
- `hour-format` — `"12"` (default) | `"24"`, 12- or 24-hour clock in time picker
- `minute-interval` — step between minute options (default: `5`)
- `second-interval` — step between second options (default: `5`)
- `show-years` — `"true"` (default) | `"false"`, toggles year select in calendar header
- `show-months` — `"true"` (default) | `"false"`, toggles month select in calendar header
- `show-days` — `"true"` (default) | `"false"`, toggles the day grid (use `"false"` for month or year picker)
- `mobile-breakpoint` — viewport width in px below which mobile mode activates (default: `768` or `--component-datepicker-mobile-breakpoint`)
- `native-mobile` — boolean, when set renders native `<input type="date">` elements on mobile instead of the popup datepicker

Events: `change` (detail: `{ value, startDate, endDate, formatted }`)
Methods: `open()`, `close()`, `clear()`
Slots: `label`, `left-icon`

```html
<y-date name="appt" format="MM/DD/YYYY" clearable>
  <span slot="label">Appointment Date</span>
</y-date>

<!-- Date range -->
<y-date name="trip" mode="range">
  <span slot="label">Travel Dates</span>
</y-date>

<!-- Date + time -->
<y-date name="meeting" show-hours format="MM/DD/YYYY hh:mm A">
  <span slot="label">Meeting Time</span>
</y-date>

<!-- Use native inputs on mobile (opt-in) -->
<y-date name="dob" native-mobile clearable>
  <span slot="label">Date of Birth</span>
</y-date>
```

### y-datepicker
Standalone calendar/date picker widget. Used internally by `y-date`; also usable on its own.

Tag: `<y-datepicker>`
Attributes:
- `mode` — `"single"` (default) | `"range"`, shows two months side-by-side in range mode; panels stack vertically on mobile
- `value` — ISO date string, or `"ISO,ISO"` comma-pair for range mode
- `min`, `max` — date constraints (ISO string)
- `format` — display format string (default: `"MM/DD/YYYY"`)
- `color` — color scheme for selected dates (default: `"primary"`)
- `show-hours` — boolean, show hour column
- `show-minutes` — boolean, show minutes column
- `show-seconds` — boolean, show seconds column
- `hour-format` — `"12"` (default) | `"24"`, 12- or 24-hour clock
- `minute-interval` — step between minute options (default: `5`)
- `second-interval` — step between second options (default: `5`)
- `show-years` — `"true"` (default) | `"false"`
- `show-months` — `"true"` (default) | `"false"`
- `show-days` — `"true"` (default) | `"false"`, set to `"false"` for a month picker; combine with `show-months="false"` for a year picker
- `mobile-breakpoint` — viewport width in px below which range panels stack vertically (default: `768` or `--component-datepicker-mobile-breakpoint`)

Events: `change` (detail: `{ value, startDate, endDate, formatted }`)
Methods: `clear()`, `formatDate(date)`

```html
<y-datepicker></y-datepicker>
<y-datepicker mode="range" show-hours show-minutes></y-datepicker>

<!-- Month picker -->
<y-datepicker show-days="false"></y-datepicker>
```

### y-select
Dropdown/multi-select. Form-associated.

Tag: `<y-select>`
Attributes:
- `options` — JSON string: `[{"value": "1", "label": "Option 1"}, ...]`
- `value` — selected value string (comma-separated for multiple)
- `name` — form field name
- `placeholder`
- `size` — `"small"` | `"medium"` | `"large"`
- `disabled` — boolean
- `required` — boolean
- `multiple` — boolean; allows multiple selections
- `display-mode` — `"tag"` renders selected items as removable tags (requires `multiple`)
- `searchable` — boolean; replaces the value display with an inline text input that filters the dropdown options as the user types (autocomplete style). In single mode the selected label is shown in the input when closed and cleared when opened. In multi-tag mode the input appears after the last tag.
- `clearable` — boolean; shows a clear (×) button when a value is selected. Works independently of `searchable`.
- `label-position` — `"top"` (default) | `"bottom"`
- `close-on-click-outside` — set to `"false"` to keep the dropdown open when clicking outside

Events: `change`

```html
<!-- Basic -->
<y-select options='[{"value":"a","label":"Option A"},{"value":"b","label":"Option B"}]'></y-select>

<!-- Searchable single select -->
<y-select searchable clearable placeholder="Search frameworks..." options='[{"value":"react","label":"React"},{"value":"vue","label":"Vue"}]'></y-select>

<!-- Multi-select with tags and inline search -->
<y-select multiple display-mode="tag" searchable options='[{"value":"a","label":"Alpha"},{"value":"b","label":"Beta"}]'></y-select>
```

### y-stack
Layout container for arranging child elements in rows, columns, grids, or masonry patterns. Purely structural — no visual styling.

Tag: `<y-stack>`
Attributes:
- `mode` — `"flex"` (default) | `"grid"` | `"masonry"`
- `direction` — `"row"` (default) | `"column"` (flex mode only)
- `columns` — number of columns for grid/masonry (default: `3`)
- `gap` — `"none"` | `"x-small"` | `"small"` | `"medium"` (default) | `"large"` | `"x-large"` | `"2x-large"` | `"4x-large"` — maps to `--spacing-*` tokens
- `wrap` — boolean, allow flex items to wrap (flex mode only)
- `align` — `"start"` | `"center"` | `"end"` | `"stretch"` (default) | `"baseline"` — cross-axis alignment
- `justify` — `"start"` (default) | `"center"` | `"end"` | `"between"` | `"around"` | `"evenly"` — main-axis distribution (flex mode only)
- `responsive` — boolean, auto-collapse columns at narrow viewports

CSS Custom Properties:
- `--component-stack-gap` — override gap spacing directly
- `--component-stack-columns` — override column count
- `--component-stack-mobile-breakpoint` — single-column breakpoint (default: `576px`)
- `--component-stack-tablet-breakpoint` — reduced-column breakpoint (default: `768px`)

CSS Parts: `container`

Events: none

```html
<!-- Row of buttons -->
<y-stack direction="row" gap="small">
  <y-button>Save</y-button>
  <y-button>Cancel</y-button>
</y-stack>

<!-- Card grid -->
<y-stack mode="grid" columns="3" gap="large" responsive>
  <y-card>...</y-card>
  <y-card>...</y-card>
  <y-card>...</y-card>
</y-stack>

<!-- Vertical form -->
<y-stack direction="column" gap="medium">
  <y-input label="Name"></y-input>
  <y-input label="Email"></y-input>
</y-stack>

<!-- Masonry layout -->
<y-stack mode="masonry" columns="3" gap="large" responsive>
  <y-card>...</y-card>
  <y-card>...</y-card>
</y-stack>
```

### y-banner
Full-width informational banner in a semantic color with matching text.

Tag: `<y-banner>`
Attributes:
- `color` — `"base"` (default) | `"primary"` | `"secondary"` | `"success"` | `"error"` | `"warning"` | `"help"`. Uses the bold content color as the background and the inverse color as text (e.g. `--success-content--` as background, `--success-content-inverse` as text) so banners stand out
- `icon` — registered icon name, renders a leading `<y-icon>`. Overridden by the `icon` slot when both are present
- `position` — `"push"` (default, in document flow) | `"overlap"` (absolutely positioned over content)
- `sticky` — boolean, when set with `position="overlap"`, fixes the banner to the viewport top on scroll
- `dismissable` — boolean, renders a close button (`<y-icon name="x">`)
- `dismissed` — boolean, reflects hidden state. Can be set programmatically
- `size` — `"small"` | `"medium"` (default) | `"large"` — controls padding, icon size, and font size

Slots: default (message content), `icon` (custom leading icon, overrides `icon` attribute), `action` (CTA element rendered before the close button)

Events: `dismiss` — cancelable, fires when close button is clicked or `dismiss()` is called

Methods: `dismiss()` (hides and fires event), `show()` (restores from dismissed state)

CSS Custom Properties: `--component-banner-padding-small/medium/large`, `--component-banner-gap`, `--component-banner-icon-size-small/medium/large`, `--component-banner-z-index` (default `200`), `--component-banner-border-radius` (default `0`)

CSS Parts: `banner`, `icon`, `content`, `action`, `close-btn`

```html
<y-banner color="success" icon="check" dismissable>Changes saved successfully!</y-banner>

<y-banner color="warning" icon="warning">
  Your trial expires in 3 days.
  <y-button slot="action" size="small" color="warning" style-type="outlined">Upgrade</y-button>
</y-banner>

<y-banner color="error" position="overlap" sticky dismissable>Server maintenance in progress.</y-banner>
```

### y-appbar
Navigation bar / sidebar. Supports vertical sidebar, horizontal top-bar, and responsive mobile hamburger modes.

Tag: `<y-appbar>`
Attributes:
- `orientation` — `"vertical"` (default) | `"horizontal"`
- `items` — JSON string: `[{"text":"Home","icon":"home","href":"/","selected":true,"children":[...]}, ...]`. Item fields: `text`, `icon` (registered icon name or inline `<svg>` string), `href`, `selected` (boolean), `slot` (custom slot name), `children` (nested sub-items rendered via y-menu)
- `size` — `"small"` | `"medium"` (default) | `"large"`
- `collapsed` — boolean, collapses vertical sidebar to icon-only mode
- `menu-direction` — `"right"` | `"down"` | `""` (auto: vertical→right, horizontal→down)
- `sticky` — `"start"` | `"end"`. Vertical: start=left, end=right. Horizontal: start=top, end=bottom
- `mobile-breakpoint` — px width below which horizontal bar collapses to a hamburger menu (default: `768` or `--component-appbar-mobile-breakpoint`)
- `history` — omit (default) for `pushState` SPA navigation; set to `"false"` for full-page `window.location.href` navigation

Events: `navigate` — cancelable; `event.detail.href`. Fires before navigation when an item with `href` is clicked. Call `e.preventDefault()` to handle routing yourself (e.g. React Router).

Methods: `toggle()` — toggles collapsed state

Slots: `logo` (icon/image in header), `title` (text beside logo), `header` (extra header content), `footer` (footer area; in mobile mode appears on the right end)

```html
<!-- Vertical sidebar -->
<y-appbar
  orientation="vertical"
  sticky="start"
  items='[{"text":"Home","icon":"home","href":"/"},{"text":"Settings","icon":"settings","href":"/settings"}]'
>
  <y-icon slot="logo" name="bolt" size="medium"></y-icon>
  <span slot="title">MyApp</span>
</y-appbar>

<!-- Horizontal top bar -->
<y-appbar
  orientation="horizontal"
  sticky="start"
  items='[{"text":"Dashboard","icon":"home","href":"/"},{"text":"Reports","icon":"chart","href":"/reports"}]'
>
  <y-icon slot="logo" name="bolt" size="medium"></y-icon>
  <span slot="title">MyApp</span>
</y-appbar>

<!-- SPA router integration -->
<y-appbar id="nav" items='[...]'></y-appbar>
<script>
  document.getElementById("nav").addEventListener("navigate", (e) => {
    e.preventDefault();
    myRouter.navigate(e.detail.href);
  });
</script>
```

- `selected` — boolean, highlights the active item
- `children` — array of sub-items (nested submenu)
- `icon-template` — `<template slot="name">` inside `<y-menu>` for a custom icon
- `template` — `<template slot="name">` inside `<y-menu>` for custom item content

```html
<y-button id="options-btn">Options</y-button>
<y-menu anchor="#options-btn" items='[{"text":"Edit"},{"text":"Delete"}]'></y-menu>

<script>
  document.getElementById("options-btn").addEventListener("click", () => {
    document.querySelector("y-menu").visible = true;
  });
</script>
```

### y-table
Data table with optional client-side sorting.

Tag: `<y-table>`
Attributes:
- `columns` — JSON string: `[{"field": "name", "header": "Name", "sortable": true}, ...]`. `sortable` defaults to `true`; set `false` to disable sorting on a column.
- `data` — JSON string: `[{"name": "Alice", ...}, ...]`
- `striped` — boolean
- `size` — `"small"` | `"medium"` | `"large"`

Events: `sort` (detail: `{ field, direction }`) — fired on header click when `sortable` is true. Direction cycles `asc` → `desc` → `none`.

```html
  striped
></y-table>
```

## Design Token System (CSS Custom Properties)

Applied by y-theme or by manually including a theme CSS file. Variables follow this naming pattern:

```
--{scheme}-background-app
--{scheme}-background-component
--{scheme}-background-hover
--{scheme}-background-active
--{scheme}-border
--{scheme}-content--
--{scheme}-content-inverse
--{scheme}-content-hover
--{scheme}-content-active
```

Where `{scheme}` is: `base`, `primary`, `secondary`, `success`, `warning`, `error`, `help`

Additional tokens:
```
--spacing-xs-small, --spacing-small, --spacing-medium, --spacing-large, --spacing-x-large
--font-size-small, --font-size-paragraph, --font-size-label
--radii-small, --radii-medium, --radii-large, --radii-full
--base-shadow
```

Component-specific tokens (subset — see `styles/variables.css` for the full list):
```
/* y-date / y-datepicker */
--component-datepicker-background       /* panel surface color */
--component-datepicker-border-color     /* panel and column-divider borders */
--component-datepicker-border-radius    /* panel and popup corner radius */
--component-datepicker-border-width     /* panel and column-divider border width */
--component-datepicker-header-color     /* day-of-week and Hr/Min/Sec column header text */
--component-datepicker-shadow           /* drop shadow on the y-date popup */
--component-datepicker-mobile-breakpoint /* viewport width in px below which mobile behavior activates (default: 768) */
--component-date-z-index                /* stacking order of the popup (default: 200) */
```

To create a custom theme, define these CSS variables in a stylesheet and point y-theme at it:
```html
<y-theme theme="/custom-theme.css"></y-theme>
```

For cross-origin theme files, add the `cross-origin` attribute:
```html
<y-theme theme="https://example.com/theme.css" cross-origin></y-theme>
```

## Icon Registry API

```javascript
import { registerIcon, registerIcons, getIcon } from "@waggylabs/yumekit";

// Register one icon (raw SVG string)
```

## Helper Functions (internal, `src/modules/helpers.js`)

These are not exported in the public API but are used internally:

- `getColorVarPair(color, fallbackColor)` — resolves a color name to `[bg, fg]` CSS value pair. Predefined names return token `var()` pairs; hex/rgb/hsl values return the raw color with a WCAG-contrasted foreground via `contrastTextColor()`
- `hideEmptySlotContainers(shadowRoot, config)` — hides wrappers when slots are empty
- `resolveCSSColor(varExpr, element)` — resolves CSS variable to computed color
- `parseColor(colorStr)` — parses hex/rgb to `{r, g, b}`
- `luminance({r,g,b})` — WCAG relative luminance
- `contrastTextColor(bgColor)` — returns `"#000"` or `"#fff"` for best contrast
